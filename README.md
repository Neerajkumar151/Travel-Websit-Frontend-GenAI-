## 🌟 Overview

**Travel Co.** is a next-generation web application built to showcase luxury travel experiences. From booking private jets to reserving exclusive villas, the platform offers a seamless, cinematic user experience.

Built with performance and aesthetics in mind, it features advanced animations, smooth scrolling, and a glass-morphic design system that sets a new standard for travel websites.

---

## ✨ Key Features

- **💎 Premium Aesthetic**: Dark-themed UI with gold accents (`#D4AF37`), glassmorphism, and sophisticated typography.
- **🌊 Smooth Scrolling**: Integrated **Lenis Scroll** for a buttery-smooth, momentum-based scrolling experience.
- **🎬 Cinematic Animations**: Powered by **Framer Motion** and **GSAP** for scroll-triggered reveals, parallax effects, and smooth transitions.
- **🔐 Secure Authentication**: Custom-built **Login/Signup** pages with toggleable forms and ambient visual effects.
- **📱 Fully Responsive**: Optimized for all devices, featuring a custom **Mobile Hamburger Navigation** with a premium full-screen overlay.
- **👆 Interactive Elements**: Global custom cursor (hand pointer) and micro-interactions on all clickable elements.
- **📹 Bento Grid Layout**: A modern, video-rich grid showcasing destinations in a dynamic layout.

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/travel-company.git
    cd travel-company
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Open the app**
    Visit `http://localhost:5173` in your browser.

## 🎨 Design System

The project uses a curated design system found in `tailwind.config.js`:

- **Colors**:
    - `brand-black`: `#0c0c0c` (Background)
    - `brand-gold`: `#D4AF37` (Accents)
    - `white/5`: (Glass Borders)
- **Typography**:
    - **Serif**: *Playfair Display* (Headings)
    - **Sans**: *Inter* (Body text)
